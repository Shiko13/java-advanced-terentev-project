# java-advanced-terentev-project
Проектная работа курса Java Advanced в Otus

Приложение предназначено для организации и контроля тренировочного процесса. Позволяет тренерам и тренируемым взаимодействовать через регистрацию, планирование и отслеживание тренировок. Также реализовано асинхронное взаимодействие между модулями через брокер сообщений.

Приложение состоит из трёх модулей:

1. **MainService** — основной сервис, отвечает за регистрацию и работу с пользователями, тренировками и активностями.

Функционал:

* Регистрация тренеров и клиентов
* Аутентификация по JWT
* Создание и получение списка тренировок
* Назначение клиентов на тренировки
* Получение активности клиентов
* Мониторинг и сбор метрик через Actuator + Prometheus

2. **TrainerWorkloadService** — сервис нагрузки тренеров
   Отвечает за подсчёт и хранение загруженности тренеров, работает асинхронно.

Функционал:

* Принимает JMS-сообщения от MainService
* Обновляет загруженность тренеров
* Предоставляет API для получения текущей загрузки

3. **EurekaServer** — дискавери-сервер, реализованный на базе Netflix Eureka, используется для регистрации и обнаружения сервисов (MainService, TrainerWorkloadService).

4. **MetricsAnalyzer** — модуль для анализа производительности и исследования поведения JVM на практике.

**Функционал и технологии:**

* **Java Agent** — для перехвата классов во время загрузки
* **WeakReference / SoftReference** — для демонстрации GC-поведения
* **Serial GC** — настройка и тестирование однопоточного сборщика мусора
* **ByteBuffer** — для управления off-heap памятью
* **JMH** — для измерения производительности коллекций
* **JMeter** — нагрузочное тестирование API (отдельные сценарии)
* **Java.util.concurrent** — использование `ConcurrentHashMap`, `Locks`, `CountDownLatch`, `Phaser` и других конструкций
* **JFR / async-profiler** — профилирование производительности
* **GraalVM** — сборка и запуск с анализом поведения
* **String Pool** — эксперименты с управлением строками

## 📈 Примеры использования и запуска

**1. Запуск Java Agent:**
java -javaagent:agent/build/libs/agent.jar -jar core/build/libs/core.jar

**2. Запуск с SerialGC и выводом GC-логов:**
java -XX:+UseSerialGC -Xlog:gc -jar core/build/libs/core.jar

**3. Профилирование с JFR:**
java -XX:StartFlightRecording=settings=profiler-scripts/jfr-template.jfc,dumponexit=true,filename=recording.jfr \
-jar core/build/libs/core.jar

**4. Нагрузочное тестирование через JMeter:**
Сценарии находятся в папке jmeter
