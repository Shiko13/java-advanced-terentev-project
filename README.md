# java-advanced-terentev-project
Проектная работа курса Java Advanced в Otus

Приложение предназначено для организации и контроля тренировочного процесса. Позволяет тренерам и тренируемым взаимодействовать через регистрацию, планирование и отслеживание тренировок. Также реализовано асинхронное взаимодействие между модулями через брокер сообщений.

Приложение состоит из четырёх модулей:

1. **MainService** — основной сервис, отвечает за регистрацию и работу с пользователями, тренировками и активностями.

Функционал:

* Регистрация тренеров и клиентов
* Аутентификация по JWT
* Создание и получение списка тренировок
* Назначение клиентов на тренировки
* Получение активности клиентов
* Мониторинг и сбор метрик через Actuator + Prometheus

2. **TrainerWorkloadService** — сервис нагрузки тренеров
   Отвечает за подсчёт и хранение загруженности тренеров, работает асинхронно.

Функционал:

* Принимает JMS-сообщения от MainService
* Обновляет загруженность тренеров
* Предоставляет API для получения текущей загрузки

3. **EurekaServer** — дискавери-сервер, реализованный на базе Netflix Eureka, используется для регистрации и обнаружения сервисов (MainService, TrainerWorkloadService).
